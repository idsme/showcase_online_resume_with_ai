# Ids Achterhof - Enterprise Architect Portfolio

A professional portfolio website showcasing the work, skills, and expertise of Ids Achterhof, an experienced Enterprise Architect specializing in digital transformation, cloud architecture, and innovative solutions.

## 🌟 Features

- **Professional Design**: Inspired by modern portfolio best practices with a clean, dark-themed interface
- **Responsive Layout**: Fully responsive design that works seamlessly on desktop, tablet, and mobile devices
- **Smooth Animations**: Engaging scroll animations and interactive elements
- **Skills Showcase**: Comprehensive skills section with visual progress indicators
- **Project Portfolio**: Featured projects with detailed descriptions and technology stacks
- **Contact Integration**: Direct WhatsApp call-to-action for easy communication

## 🎨 Design

The design features:
- **Color Scheme**: 
  - Background: Navy/Slate (`rgb(15, 23, 42)`)
  - Text: Light slate (`rgb(226, 232, 240)`)
  - Accents: Teal/Cyan (`rgb(94, 234, 212)`)
- **Typography**: Clean, professional fonts with excellent readability
- **Layout**: Fixed sidebar navigation with scrollable content area

## 🛠️ Technologies

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS Grid and Flexbox
- **JavaScript**: Vanilla JS for interactions and animations
- **Font Awesome**: Icons
- **No frameworks**: Pure, lightweight code for optimal performance

## 🚀 Getting Started

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/idsme/showcase_online_resume_with_ai.git
   cd showcase_online_resume_with_ai
   ```

2. Open `index.html` in your browser:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Or using Node.js
   npx http-server
   ```

3. Visit `http://localhost:8000` in your browser

### Deployment

This is a static website and can be deployed to any static hosting service:

- **GitHub Pages**: Push to `gh-pages` branch
- **Netlify**: Connect your GitHub repository
- **Vercel**: Import your GitHub repository
- **AWS S3**: Upload files to S3 bucket with static hosting enabled
